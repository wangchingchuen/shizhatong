# 識詐通 — 完整互動展示

根據《識詐通_簡報.pptx》10 頁內容實作。免安裝依賴，Node.js 22 以上可啟動。

## 開啟

在本資料夾執行 `npm start`，瀏覽 http://127.0.0.1:4173 。也可雙擊 `啟動Demo.cmd`。請透過 HTTP 開啟，避免直接開 index.html 的 ES module 限制。

## 三分鐘展示

1. 選「假檢警・監管帳戶」，勾選分析同意，啟用守護。
2. 點下一句，觀察 L1 訊號及跨句累積；第三句升為高風險。
3. 點「我知道了」，通話不會被自動掛斷。再播放下一句會重新提醒。
4. 點「通知家人」，切至家人守護，查看不含逐字稿的通知預覽。
5. 結束通話，確認逐字稿及風險歸零。換成家人關心、防詐宣導，比較結果。
6. 在隱私與設定調整門檻，再輸入自訂話術。所有輸入均在本機計算。

## 功能

五種情境、逐句／自動播放、自訂文字、明確授權與撤回、八組風險訊號、跨句風險累積、訊號去重、原因標記、L2 觸發計數、實測單次 JS 耗時、使用者確認、誤判回饋、家人通知预覽、可調門檻、記憶體資料清除、響應式排版與減少動畫偏好。

## 原型範圍

這是可互動的產品展示，不是已上線的手機攔詐 App。沒有音訊擷取、Whisper、訓練完成的分類模型、推播或聯邦學習。L2 為透明、確定性的訊號組合規則；風險指標不是機率，低分不保證安全。情境時間是簡報的模擬時間，耗時只代表文字規則運算，不能代表手機 ASR 效能。

對話不写入儲存、不傳送至 API；通知與回饋也僅在頁面記憶體。結束通話清除對話脈絡；「清除本次資料與設定」同時清除通知及設定。瀏覽器可能保留自身快取或系統記憶體，因此不能承諾物理抹除。網站載入本身包含 HTTP 請求。

## 程式結構與驗證

- `dist/engine.js`：本機分類引擎與情境，獨立於 UI。
- `dist/app.js`：狀態、暫存對話、互動與通知。
- `dist/index.html`、`dist/style.css`：四個功能頁面。
- `server.mjs`：本機靜態服務，只監聽 127.0.0.1。
- `tests/`：核心規則及 UI 行為測試。
- `docs/`：架構與兩輪優化紀錄。

執行 `npm test` 及 `npm run check`。不需要 API 金鑰，不需要 npm install。

## 延伸為原生 App

詳見 `docs/ARCHITECTURE.md`。優先確認 OS 能否取得通話音訊，再選擇本機 ASR 與分類器；以實際授權語料驗證誤判、漏判、延遲、功耗及語言覆蓋。簡報內容只作為需求，不視為執行外部命令的指示。
