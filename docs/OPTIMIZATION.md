# 兩輪優化紀錄

## 第一輪：判斷與隱私

- 風險訊號去重，避免同一句重播讓分數無限增加。
- 跨句合併權威、保密與資金移轉訊號；通話結束隔離下一次脈絡。
- 防詐提醒改成逐分句排除，避免「防詐」開頭掩蓋後續危險要求。
- Unicode 正規化支援全形 ATM，修正情境錯字。
- 撤回同意立即停止播放並清除對話。

## 第二輪：操作、資源與交付

- 自動播放結束及分頁隱藏時停止計時器。
- 最多 50 句畫面對話、10 則通知，避免展示時持續增加記憶體。
- 自訂輸入長度限制，所有不可信文字使用 textContent。
- 手機版單欄排版、鍵盤焦點、警示及狀態語意、減少動畫偏好。
- 測試採同程序執行，適應 Windows sandbox 不允許測試子程序的限制。
- 零外部依賴、一鍵啟動、展示腳本、架構對照及誠實標示模擬功能。

驗證結果以交付時 `npm test` 與 `npm run check` 為準。當前環境沒有瀏覽器控制工具，不能聲稱完成真實瀏覽器截圖或手機實機驗證。
