# 實作對照與產品延伸

| 簡報需求 | Demo | 正式產品工作 |
| --- | --- | --- |
| 主動啟用 | 每次通話勾選同意，可撤回 | 原生授權與系統通話限制確認 |
| L1 常駐 | 每句規則匹配 | 輕量串流訊號、功耗評估 |
| L2 可疑才啟動 | 有訊號才進入意圖組合，記錄啟動數 | 本機 ASR 與量化分類模型 |
| 即時警示 | 分數、理由、確認與誤判回饋 | 可及性、通話介面整合 |
| 不留音訊／逐字稿 | 不取得音訊，文字只留記憶體 | 串流緩衝與資料生命週期稽核 |
| 家人守護 | 純通知預覽 | 雙方同意、加密推播、撤回與刪除 |
| 聯邦學習 | 意願開關，沒有傳輸 | 匿名化更新、差分隱私、安全聚合、模型簽章 |

## 資料生命週期

文字輸入 → 正規化及安全宣導分句 → L1 訊號 → 去重累積 → 組合權重 → 門檻 → UI。最多顯示 50 句暫存對話、10 則通知，限制展示記憶體成長。結束清除對話；全資料清除重設所有本次設定。UI 以 textContent 建立不可信文字，避免 HTML 執行。

## 模型介面建議

原生端的串流 ASR 回傳 `{text, isFinal, language}`；最終句觸发 L1，在可疑時調用本機意圖分類器，回傳 `{labels, confidence, modelVersion}`。不要將示範規則分數直接當作模型 confidence。UI 只能獲取風險理由與警示狀態；家人端只收使用者授權的最小摘要。

## 評估與限制

分別量測詐騙類型的 precision、recall、F1、每小時誤報、偵測時間、裝置功耗。語料需包含正常銀行提醒、否定句、多輪誘導、國語／台語、雜訊及對抗改寫。此 demo 的測試只驗證程式規則，不證明真實反詐準確率。聯邦學習只傳參數也不能自動保證匿名性。作業系統音訊存取與合法授權需由原生實驗和正式審查確認。
